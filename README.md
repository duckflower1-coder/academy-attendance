# 학원 출결관리 시스템

원장님이 학생 카드를 눌러 **등원 → 하원**을 체크하면, 학부모님 휴대폰으로 즉시 알림(ntfy)이 가고
학부모 전용 페이지에서 등·하원 시간을 확인할 수 있는 웹앱입니다.

- `index.html` : 원장용 (로그인 필요) — 오늘 출결 / 출결 기록(시간 수정·CSV) / 학생 관리(학부모 링크·QR)
- `parent.html?c=코드` : 학부모용 (학생별 고유 링크, 최근 60일 기록, 30초 자동 새로고침)
- 저장소: Supabase (`att_` 테이블) · 알림: ntfy.sh (무료) · 배포: GitHub Pages (Settings › Pages › Deploy from a branch › main / root — 파일을 올리거나 고치면 자동 재배포)

## 처음 한 번만 설정

1. **Supabase 테이블 만들기** — 대시보드 › SQL Editor 에 `supabase.sql` 내용을 붙여넣고 Run.
2. **로그인 계정** — 버스 탑승시스템의 **관리자(admin) 계정 그대로** 로그인합니다.
   (버스 시스템의 학부모·도우미 계정으로는 출결 데이터를 볼 수 없습니다)
3. **config.js** 에 학원 이름, Supabase URL, anon public key 를 넣고 저장(커밋)하면 자동 배포됩니다.
   (버스 시스템과 같은 Supabase 프로젝트 사용. service_role 키는 절대 넣지 마세요)

## 사용법

- 학생 관리 탭에서 학생 등록 → `링크·QR` 버튼으로 학부모에게 링크 전송(문자 버튼 / 복사).
- 학부모는 링크에서 ntfy 앱 설치 후 `구독하기`를 누르면 이후 등·하원 알림을 받습니다.
- 잘못 눌렀으면 5초 안에 **되돌리기** → 알림이 가지 않습니다. (알림은 5초 뒤 발송)
- 원장용 페이지는 휴대폰 홈 화면에 추가해 앱처럼 쓰면 편합니다.
